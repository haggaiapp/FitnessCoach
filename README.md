# מאמן כושר אישי – אפליקציית אנדרואיד (טלפון + טלוויזיה)

תוכנית אימונים מקצועית בעברית עם הדמיות מונפשות, מאמן קולי, התקדמות הדרגתית לפי רמות, ותמיכה מלאה בשלט טלוויזיה.

## מה יש באפליקציה
- **57 תרגילים עם הדמיה מונפשת**: חימום (8), בטן וליבה (10), פלג גוף עליון (11), רגליים (4), משקולות יד (12), מכשיר (7), מתיחות (5).
  התרגילים משתי האפליקציות המצורפות מסומנים ב-★ (Impossible Abs / Impossible Upper Body).
- **תוכנית מאמן**: 5 רמות × 4 שבועות × 4 אימונים (עליון+משקולות · בטן וליבה · רגליים · מכשיר/מעגל גוף מלא).
  כל שבוע 4 הוא שבוע התאוששות (נפח מופחת). מעבר רמה נפתח אחרי 12 אימונים.
- **כל אימון**: חימום → אימון עיקרי בסטים עם מנוחות → שחרור ומתיחות.
- **התאמה אישית**: מבחן כושר בפתיחה לקביעת רמה, משוב בסוף אימון (קל/בדיוק/קשה) שמשנה חזרות ומשקלים, המלצת משקל לפי המשקולות שברשותכם.
- **נגן אימון**: ספירת חזרות אוטומטית מסונכרנת להדמיה, טיימר, מנוחה עם תצוגת התרגיל הבא, הנחיות קוליות בעברית, צלילים, השהיה/דילוג.
- **טלוויזיה**: מופיעה במסך הבית של Android TV / Google TV, ניווט מלא בחצים ו-OK, כפתור Play/Pause בשלט, גופנים מוגדלים.

## התקנה – 3 אפשרויות
1. **Android Studio** (מומלץ): File ▸ Open ▸ בחרו את התיקייה `FitnessCoach` ▸ המתינו לסנכרון ▸ Build ▸ Build APK(s).
   קובץ ה-APK ייווצר ב-`app/build/outputs/apk/debug/`. העבירו לטלפון/טלוויזיה והתקינו (יש לאשר "התקנה ממקורות לא ידועים").
2. **GitHub (בלי להתקין כלום)**: העלו את התיקייה למאגר GitHub ▸ לשונית Actions ▸ "Build APK" ▸ הורידו את ה-APK מה-Artifacts.
3. **בדיקה מיידית בדפדפן**: פתחו את `app/src/main/assets/www/index.html` ב-Chrome (מחשב/טלפון).

## התאמת "המכשיר"
קובץ ה-PDF של המכשיר (הקישור ב-cloudfront) לא היה נגיש לקריאה, ולכן תרגילי המכשיר בנויים לתחנת כבלים/מולטי-ג'ים ביתית:
לחיצת חזה, פולי עליון, חתירה בכבל, פשיטת ברכיים, כפיפת ברכיים, פשיטת מרפקים בפולי, כפיפת מרפקים בכבל.
- לעדכון התרגילים: `www/js/exercises.js` (קטגוריה `machine`).
- לעדכון הרכב יום המכשיר: `www/js/program.js` (`MAIN.D`).
- אין מכשיר? בהגדרות כבו "יש לי את המכשיר" – יום 4 יוחלף במעגל גוף מלא.
